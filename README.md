eSewa Data Analyst Assessment, Round 2

This folder contains my submission for the Round 2 technical assignment.

Contents
1. Executive_Report.pdf A short, plain-language summary of the key findings and recommended actions, written for the leadership team.
2. Detailed_Analysis_Report.pdf The full analysis report covering all four tasks: data quality, exploratory analysis with statistical checks, customer segmentation, trend outlook, and the dashboard.
3. esewa_assignment.pbix The interactive Power BI dashboard with all visuals across four pages: executive overview, growth and onboarding, risk and reliability, and customer segments.
4. esewa_assessment_code.ipynb The Jupyter notebook with the complete code, from dataset generation and cleaning to features, charts, segmentation, and dashboard exports. Running it end to end regenerates every number and figure in the reports.
5. eSewa_Findings_Presentation.pptx contains the powerpoint file of the key findings and recommended actions, written for the leadership team.


Note on the data

No dataset was provided, so the analysis uses a synthetic dataset of 1 million users and 25 million transactions, inspired by a digital wallet business. The findings demonstrate method and reasoning, not facts about any real company.
